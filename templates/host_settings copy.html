Custom System Prompt

Enter a custom system prompt to control how the LLM grades student responses. Leave empty to use the default grading rubric. The prompt should instruct the LLM to return JSON with the required fields.

Default Grading Rubric

This is the default rubric used when no custom prompt is set. You can copy and modify this as a starting point. 

{{ default_rubric }}

Required JSON Output Format

Your custom prompt should instruct the LLM to return a JSON response with these keys: 

{
    "total_score": <number>,
    "category_scores": {
        "conceptual_understanding": <number out of 20>,
        "application_of_theories": <number out of 15>,
        "use_of_terminology": <number out of 15>,
        "critical_thinking": <number out of 15>,
        "clarity_of_explanation": <number out of 15>,
        "completeness": <number out of 10>,
        "examples_and_evidence": <number out of 10>
    },
    "grading_reasoning": "<explanation of scoring>",
    "strengths": ["strength 1", "strength 2"],
    "improvements": ["improvement 1", "improvement 2"],
    "overall_comments": "<summary>"
}
